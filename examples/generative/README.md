# Seeded Constellation

This three-track Plaits instrument uses the same `meldritch.musical` project,
track, pattern, arrangement, editing, and Lua persistence layer as the
eight-track groovebox. Its 24-, 32-, and 48-step note loops are generated by
ordinary deterministic Lua.

```sh
cargo run -- perform examples/generative/generative.lua
```

`F10` opens the shared track editor and `F9` returns to performance. `[`/`]`
select eight-step banks in a sixteen-step viewport, `1`-`8` toggle the selected bank, `n`/`N` choose viewed
material independently of playback, and pitch, gate, velocity, clear, rotate,
mute and solo use the same semantic commands as the groovebox. `S` atomically
saves `generative-edits.lua`. Reload it without rewriting the generator:

```sh
cargo run -- perform examples/generative/project.lua
```
