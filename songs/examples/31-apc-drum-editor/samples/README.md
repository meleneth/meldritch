# Original 909-inspired kit

These eight 48 kHz mono PCM16 WAVs are generated by `python3 generate.py`.
They are original synthetic approximations, not Roland recordings and not a
faithful TR-909 circuit model. MELDRITCH has no native 909 engine. The sampler
plays the complete one-shot hit; note duration does not truncate its tail.

Kick/toms use pitch-swept damped sine waves; snare mixes damped body partials and
filtered deterministic noise; clap uses three short noise bursts plus a tail;
hats/ride combine metallic partials and noise with different decay times.
Seeds, formulas, gain and envelopes are in the generator. Samples can be replaced
through the existing bank; no hidden drum instrument or controller policy lives
in Rust. Open/closed hats are independent overlapping hits; choke groups and
live drum synthesis parameter editing are not implemented.
