# Meldritch 1 archive

Meldritch 1 is completed research into software-defined modular synthesis.
Its source, examples, fixtures, documentation, and Git history remain in this
repository. [Meldritch 2](../meldritch2) is the active project and has no
backward-compatibility obligation to the old project.

Read the [archive guide](https://github.com/meleneth/meldritch/blob/main/MELDRITCH1_ARCHIVE.md)
for the historical purpose, outcomes, limitations, independent build commands,
and candidate reusable assets. The original [architecture](../ARCHITECTURE),
[example capabilities](../examples/capabilities), and [research queue](../TODO)
remain available as historical documents.
